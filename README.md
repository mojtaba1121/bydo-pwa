# بایدو PWA

نسخه اولیه رابط کاربری اپ دوچرخه اشتراکی بایدو؛ فارسی، راست‌چین، mobile-first و قابل نصب به‌صورت PWA.

## اجرا

```bash
npm install
npm start
```

ساخت نسخه production:

```bash
npm run build
```

صفحات فعلی: ورود، نقشه ایستگاه‌ها، انتخاب دوچرخه، رزرو و تایمر، اسکن QR، گزارش خرابی، سفر فعال، سفرها، کیف پول و پروفایل.
